# DIRECTV Live TV for iPod touch 4G

Status: implemented first slice. This document extends the current
`docs/livetv-directv-guide-spec.md` in RockBox_Personal-master; that Classic
implementation remains the schedule and visual authority.

## Product contract

DIRECTV is a standalone landscape UIKit application for `iPod4,1` on iOS
6.1.6 and 7.1.2. It brings RockPod Live TV to the touch without bringing the
RockPod music Store, video browser, or device-library sync into the app.

The initial touch line-up contains the existing local Weather channel, USA
Network, and YTV. A user pairs the app with the same RockPod companion used by
RockPod Store, taps Sync, and the host prepares iPod-touch copies of those
channels' schedules and media.
Once the transaction completes, watching and guide browsing are entirely
local and do not require Wi-Fi.

This is simulated linear television, not IPTV. The device uses its wall clock
to join the scheduled file at the elapsed offset, exactly as the Classic does.
No content is fetched from a television provider and no DIRECTV service or
credentials are used.

## Parity baseline

The implementation was checked against the current Rockbox sources and the
passing `tools/livetv_guide_sim_gate.py` capture, not merely the older prose
spec. The touch guide keeps these current behaviors:

- Sunday-zero, seven-day schedule generated by `LiveTvScheduler`;
- show and commercial slots grouped into one guide programme block;
- wall-clock tune and join-in-progress behavior;
- the current 68/320 channel-column proportion and three half-hour columns;

restart the channel.

## RockPod sync architecture

The host companion is authoritative:

```text
RockPod LiveTvLibrary + LiveTvLineup
              |
              v
LiveTvScheduler (the same weekly slots as Classic)
              |
              v
Classic MPEG cache -> touch H.264/AAC cache
              |
              v
authenticated manifest + ranged downloads
              |
              v
DIRECTV.app/Documents/LiveTV
```

The touch exporter calls the existing scan, line-up, Weather builder,
reconciliation, scheduler, and Classic MPEG cache. It never implements a
second schedule algorithm. Unique Classic media paths are transcoded once to
480x360 H.264 Baseline Level 3.0/AAC MP4 and cached under the RockPod cache
directory. Schedule slots point to opaque media IDs rather than host paths.

Sync is a publication transaction:

1. `POST /v1/livetv/syncs` starts an asynchronous preparation job. The first
   app sends `{"scope":"featured"}` for Weather, USA Network and YTV.
   `forecast` remains available for Weather-only diagnostics and `all` is
   supported for expanding to the complete line-up.
2. `GET /v1/livetv/syncs/<id>` reports scan/transcode progress and eventually
   returns the immutable manifest.
3. The app downloads missing media through
   `GET /v1/livetv/media/<opaque-id>` using HTTP Range resume.
4. Only after every expected byte count is present does the app atomically
   replace its local manifest. An interrupted sync therefore keeps the last
   playable line-up.

All endpoints except status and pairing use the existing bearer token. Host
paths, ffmpeg commands, provider state, and credentials are not serialized.

## Manifest v1

The manifest contains:

- `version`, `revision`, `generated_at`, `scope`, and `timezone`;
- channels: number, callsign, name, category, favourite, parental lock;
- seven days of slots: channel, Sunday-zero day, start, duration, kind,
  title, rating, description, block start/duration, and media ID;
- media: opaque ID, byte count, SHA-256, and authenticated download URL.

The revision is a SHA-256 digest of the public manifest body. Repeated syncs
with unchanged schedule and encoded files produce the same revision.

## Touch controls

- Tap a programme to select it; tap the selected currently-airing programme
  or the picture-in-guide to watch full screen.
- Swipe vertically to move through channels.
- Swipe horizontally to move the guide window in half-hour increments.
- Tap the red/green hint controls for -12/+12 hours.
- Tap Sync to refresh from RockPod. The first run presents host URL and
  six-digit pairing fields.
- Tap full-screen video to return to the guide without replacing the player.
- Swipe left/right while watching to tune the adjacent playable channel.

Seeking, pausing, background playback, recording, on-device schedule edits,
and provider streaming are deliberate non-goals. The app catches up from the
wall clock whenever it becomes active.

## Acceptance gate for the first slice

- The Classic simulator guide gate still passes unchanged.
- Host tests prove Weather-only and featured-line-up filtering, stable schedule
  serialization, opaque media addressing, cache reuse, and failed-transcode
  non-publication.
- On `iPod4,1`, the app pairs, completes a forecast-only sync, opens directly
  on the Weather guide, joins the current hour at the correct offset, moves
  the same player between guide and full screen, and plays after Wi-Fi is
  disabled.
