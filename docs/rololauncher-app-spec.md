# RoloLauncher personal application

RoloLauncher is a personal iPod 6G Applications entry for starting the
isolated nightly TV-out test build without replacing the established RockPod
firmware or changing the installed dual bootloader.

## Runtime contract

- Launcher firmware: `/rockbox-tvout-test.ipod`
- Isolated runtime directory: `/.rbtv`
- Main RockPod firmware: unchanged
- Apple firmware boot path: unchanged

Selecting RoloLauncher verifies that both the alternate firmware and runtime
directory exist, then passes the firmware to Rockbox's built-in RoLo loader.
RoLo performs the normal playback shutdown and firmware validation.  A load
failure returns to the main UI; a successful load does not return.  Rebooting
the iPod loads the established RockPod firmware again.

The iPod 6G simulator exposes the same Applications entry and path checks for
UI regression testing.  Since simulator builds do not implement RoLo, a fully
staged simulator reports that firmware loading requires iPod hardware instead
of attempting the switch.

The launcher is compiled only for iPod Classic 6G/7G.  It must not appear on
iPod Video 5G because the candidate firmware has a different target model.

## Applications icon

The master image is
`assets/ipodjs/sources/applications/generated/rololauncher-ios3.png`.  It uses
a silver reload arrow around a firmware chip on blue enamel, with the same
late-2000s glass treatment as the other custom Applications icons.  The
deterministic 46-pixel runtime derivative is generated by
`tools/prepare_ipodjs_application_icons.sh`.

The Applications icon cache increases from 20 to 21 slots.  It remains a
member of the existing preview-storage union and stays smaller than the two
full preview slots, so this change does not increase the union's BSS size or
borrow memory from playback.

## Test gate

1. Build the iPod 6G simulator and native firmware.
2. Confirm RoloLauncher appears with its icon in both Applications layouts.
3. With no candidate installed, selecting it reports the missing firmware and
   returns to Applications.
4. With only the candidate firmware installed, selecting it reports the
   missing runtime files.
5. With both paths installed, verify the candidate starts and uses `/.rbtv`.
6. Reboot and verify the established RockPod firmware still starts normally.
7. Verify the Hold-switch Apple firmware path remains unchanged.

Any future hardware-button third-boot selector belongs to the personal
bootloader tree.  It is not part of RoloLauncher or the upstream TV-out repo.
