# iPod 6G RetailOS 2.0.4 Hibernate Gap Matrix

## Playback qualification update — 22 September 2026

P15 was deployed with user authorization. The user reports repeated retained
screen/music-position restoration, but playback is silent and stationary;
Play/Pause twice does not recover it. P16 now saves and restores the CS42L55
register bank lost with its Standby supply, verifies clock/output settings, and
blocks output on restore failure. The clean build, ten host tests and final
ABI-12 linked-image gate pass. P16 is not yet deployed or hardware qualified.
See [the P16 qualification record](../ipod6g-hibernate-p16-validation.md).
Earlier P15/P14 status statements below are historical. The mounted Nano 3G
is not the test Classic; ask the user before deploying any new candidate.

This matrix treats the decrypted RetailOS image with SHA-256
`f4368251a58b2fdc7b46acf3178dae1d24bc1e029736240741015851256c65c4`
as the behavioral specification. Address claims refer to that exact image.

The latest hardware boundary is P14: its first retained cycle restored, but
its second consecutive cycle again returned a frozen framebuffer. P15 is a
source-level candidate only; it has not yet been qualified on hardware.

## Research stop condition

Do not claim hardware parity until the media-service pair, relevant VIC state,
outer service ordering, wake-input consumption, and repeat hardware behavior
are all matched or explicitly shown to be inapplicable to Rockbox's
architecture. Do not deploy a new candidate without explicit user authorization.
