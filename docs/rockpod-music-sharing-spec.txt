RockPod Music Sharing
=====================

Goal
----

Add a Store sub-tab where two RockPod installs can exchange music recommendations when they are not on the same network. Shared items can be albums, songs, or playlists. Each received item has a Buy action that uses the same streamrip-backed store import path as the Music store.

Connection Model
----------------

Both installs use:

- A shared relay URL, preferably HTTPS.
- A shared pair code.
- A local display name.

The relay stores small JSON share cards by pair code. It does not store music files. Each app can send a card with POST /v1/share and refresh incoming cards with GET /v1/inbox?pair_code=...

The repository includes rockpod/scripts/music_share_relay.py as a minimal reference relay. It can run on a VPS, home server exposed through an HTTPS tunnel, or any public host reachable by both users.

Share Card
----------

Each message contains:

- id
- created_at
- sender_id
- sender_name
- item.kind: album, track, or playlist
- item.title
- item.artist
- item.url
- item.note

item.url should be a streamrip-supported URL, such as Tidal/Qobuz/Deezer album or track links, SoundCloud links, or Spotify playlist links. RockPod converts Spotify playlist URLs to Tidal imports through the existing playlist import flow.

UI
--

The Sharing tab uses the existing Store visual language:

- itunes_store_nav
- itunes_store_hero
- itunes_store_import_bar
- itunes_store_panel
- itunes_store_detail_row
- store_buy_button

The tab includes relay settings, a compose row, an Inbox table, a Sent table, status text, and an import/download table for Buy progress.

Privacy
-------

The pair code is a routing secret, not encryption. The relay operator can read share cards. Use HTTPS and a private pair code for personal use.
