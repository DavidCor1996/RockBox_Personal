1. Copy the file 'podzilla' to your iPod.
2. Copy everything in the folder 'ipod' to your ipod. Make sure you don't copy the folder 'ipod', just everything in it.
3. You don't need to make a start file, I already made one.
4. Make sure you have ipodlinux installed correctly.
5. If Sash doesn't start up by itself, type "false" (no quotations) at the end of 'rc' in /etc.
6. Have fun!
