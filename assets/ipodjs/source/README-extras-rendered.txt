iPodJS Extras rendered preview assets
======================================

The Extras-menu right-pane objects are rendered raster assets rather than
hand-drawn LCD primitives. The generated source sheet is stored as
ipodjs-extras-rendered-source.png and its keyed transparent master as
ipodjs-extras-rendered-transparent.png.

Run tools/generate_ipodjs_extras_previews.sh from the repository root to
rebuild the light/dark 174x240 and 174x220 Rockbox BMP panes. The generated
objects contain no third-party logos or text.
